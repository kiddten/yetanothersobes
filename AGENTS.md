# Работа с техническими разборами

- Это Quarto Blog; используйте установленный Quarto 1.10.18.
- Новые материалы: `posts/<ascii-slug>/index.qmd`; образец в `templates/post.qmd`.
- Пишите по-русски, сохраняйте общепринятые технические термины.
- Превращайте чат в самостоятельный разбор: контекст, механизм, пример,
  ограничения, источники. Учитывайте поздние исправления, не копируйте сырой чат.
- Указывайте фактическую дату подготовки статьи и содержательные категории.
- Mermaid: блоки `{mermaid}`. Примеры кода по умолчанию не исполняются:
  используйте `python`, а не `{python}`. Не добавляйте Python/R-зависимости
  для обычных текстовых разборов.
- Проверяйте `quarto render` и отображение изменённых страниц в браузере.
  При изменении интерактивности проверяйте её поведение, обе темы и узкую ширину.
- Не редактируйте `_site/` вручную. Не добавляйте сборку и кеш в Git.
- Сейчас проект используется локально. Не создавайте удалённый репозиторий,
  не отправляйте изменения и не публикуйте сайт без запроса пользователя.
